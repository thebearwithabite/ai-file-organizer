# Promotional Video Script: AI File Organizer

## Production Notes
- **Length**: 90 seconds
- **Target Audience**: Creators, producers, and developers seeking an intelligent, low-friction file solution.
- **Tone**: Cinematic, inspiring, and focused.
- **Music**: High-energy ambient electronic with a rhythmic build.
- **Visuals**: Dynamic split-screens, custom motion graphics showing folders organizing themselves, crisp UI captures.

---

## Script Flow

### Scene 1: The Friction (0:00 - 0:15)
*   **Visual**: A close-up of a desktop screen showing 200+ cluttered file icons. Slow tracking shot of a user rubbing their temples in frustration.
*   **On-Screen Text**: *Friction. Chaos. Cognitive Load.*
*   **Music**: Subdued, slightly discordant synth tones.
*   **Narration (Voiceover)**:
    "Organizing files is a chore. If you have ADHD or manage creative pipelines, it's a cognitive barrier that stalls your momentum."

### Scene 2: The Transition (0:15 - 0:35)
*   **Visual**: Cut to a clean dark-mode command line running `interactive_organizer.py`. Files start moving into subfolders. An elegant glassmorphic interface reveals confidence indicators.
*   **Action**: A graphic overlay shows a PDF transitioning into vector embeddings, then a photo being scanned by vision AI.
*   **On-Screen Text**: *Say Hello to Your AI Librarian.*
*   **Music**: A rhythmic, satisfying beat drops in.
*   **Narration (Voiceover)**:
    "The AI File Organizer changes that. It combines text analysis, computer vision, and audio diagnostics to automatically categorize, rename, and stage files as they arrive."

### Scene 3: The Features (0:35 - 1:00)
*   **Visual**: A montage of three 5-second highlights:
    1.  *Exclusion Gate*: Pointing out a `.noai` folder, showing it remains completely private.
    2.  *Confidence Gate*: Showing a 95% confident match organizing instantly, while a 70% match opens a simple, binary AppleScript popup.
    3.  *ADHD Mode*: Showing clean, truncated paths that reduce visual clutter.
*   **On-Screen Text**: *Automated. Private. ADHD-Friendly.*
*   **Narration (Voiceover)**:
    "It works seamlessly behind the scenes. Staging folders are scanned, confidence thresholds gate automatic moves, and privacy zones are strictly respected."

### Scene 4: RAG Retrieval & The RAG Loop (1:00 - 1:20)
*   **Visual**: Open a terminal and run `agno_retrieval_loop.py`. Type: *"Summarize my active podcast folders."* The RAG agent extracts metadata, analyzes files, and spits out a structured markdown summary.
*   **On-Screen Text**: *Talk to Your Archive.*
*   **Narration (Voiceover)**:
    "And with the new Agno retrieval loop, your archive becomes a living resource. Search, query, and chat with your files in plain English. RAG, simplified."

### Scene 5: Outro (1:20 - 1:30)
*   **Visual**: Clean, premium ending slide with the repository logo, GitHub stars count rising, and the URL.
*   **Music**: Resolves to a clean, inspiring chord.
*   **On-Screen Text**:
    *   **AI File Organizer**
    *   *Intelligent macOS Librarian & RAG Portal*
    *   `github.com/thebearwithabite/ai-file-organizer`
*   **Narration (Voiceover)**:
    "Stop sorting. Start creating. Clone it on GitHub today."
